## The task

Write one line, at most 180 characters, labelling an ordinary office object
as an ancient artifact — a museum placard for something dug from a lost
civilisation, with a catalogue date, a material and a provenance. A
dry-witted curator judge picks the funnier, more inventive placard.

## The entry

> Small yellow tablet, adhesive-backed, c. 2023. Bears a single plea — 'DO NOT TOUCH' — in a hand now lost to the ages. Recovered from the last biscuit in the tin.

A sticky note is a clay tablet; its "DO NOT TOUCH" is a plea from a
vanished hand; it was recovered guarding the last biscuit in the tin. The
joke is that a note protecting office biscuits gets the same solemn
treatment as a tablet guarding a tomb — catalogue date, material,
provenance, and a hand lost to the ages.

## Run

```sh
node main.ts
```

Writes the placard line to `/output/entry.txt` (161 characters, one line).
